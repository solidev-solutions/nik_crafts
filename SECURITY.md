# Security Policy

## Supported Versions

Only the latest release of a supported branch gets fixes.

| Branch       | Frappe and ERPNext | Supported |
| ------------ | ------------------ | --------- |
| `version-16` | version 16         | Yes       |

## Reporting a Vulnerability

Please do not report security issues in public issues or pull requests.

Report them privately through [GitHub's vulnerability reporting](https://github.com/solidev-solutions/nik_crafts/security/advisories/new) or by e-mail to security@solidev.solutions.
